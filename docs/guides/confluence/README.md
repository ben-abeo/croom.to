# Confluence pages for the conference rooms

The Markdown here is the text of the Crystal Meet pages in the CM Confluence space, under its overview page. The PDFs in `docs/guides` are the same text with the Crystal PM layout: attach each one to its page.

Page tree (the file name gives the order):

- `00-getting-started.md`: **Conference rooms: getting started**, the landing page. Attach `crystal-meet-employee-guide.pdf`.
  - `10-reserve-google-calendar.md`: Reserve a room in Google Calendar
  - `20-google-meet.md`: Book a room with Google Meet
  - `30-zoom.md`: Book a room with Zoom
  - `40-door-sign-and-table.md`: Book at the door sign or table screen
  - `50-join-and-run.md`: Join and run a call from the table
  - `60-teams-webex-laptop.md`: Teams, Webex and laptop meetings
  - `80-troubleshooting.md`: Conference room troubleshooting
  - `90-technical-manuals.md`: **Conference room technical manuals**, for administrators
    - `91-touch-pi-manual.md`: Touch Pi technical manual. Attach `crystal-meet-touch-pi-manual.pdf`.
    - `92-tv-pi-manual.md`: TV Pi technical manual. Attach `crystal-meet-tv-pi-manual.pdf`.
    - `93-door-sign-manual.md`: Door sign technical manual. Attach `crystal-meet-door-sign-manual.pdf`.

A name in square brackets, such as `[Book a room with Zoom]`, is a link to the page with that title; make it a real link when you publish.

The employee pages and the manual pages are generated from the guides' `index.html`, so change the guide, rebuild its PDF, and then copy the change here.
