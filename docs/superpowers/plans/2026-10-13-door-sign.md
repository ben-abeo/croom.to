# Door Sign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The door sign reads from the hallway without a coloured wall: a status rail, a solid chip and a tinted Austin scenery; the company name and logo, the room name, the status, the next bookings, a week view, the clock and date; four selectable backgrounds; an optional Longhorns scoreboard, off by default.

**Architecture:** The sign page (`sign.html/css/js`) is restyled and gains the week view and the scoreboard strip, reading everything from `/api/status` and two routes. The control service adds `/api/calendar/week` (the calendar service already holds a week of events), two room settings (`sign_background`, `sign_scores`) through `/api/settings`, `room.company` from the config, and `scores` in the status when the scoreboard is on. A new `croom.scores` package fetches ESPN's public schedule feed behind an injectable fetcher with a ten-minute cache. The touchscreen's Options gets a Door sign card.

**Tech Stack:** vanilla JS/CSS with inline SVG, aiohttp, Playwright tests, pytest with a saved JSON fixture.

**Spec:** `docs/superpowers/specs/2026-10-13-door-sign-design.md`

**Base:** branch `door-sign` from `main`. The `/api/settings` route also arrives on branch `keyboard` (its `key_click` key); whichever merges second resolves the route to one implementation with a whitelist of keys.

## Global Constraints

- Internal names stay `croom`; Crystal Meet and the configurable company name in copy; no attribution lines.
- Tests: `.venv/bin/pytest -q -p no:cacheprovider -W error <path>`; the sign tests drive real Chromium; never the whole suite from a task.
- Every existing door sign test in `tests/unit/control/test_page.py` keeps passing, or is changed deliberately with the reason in the commit message (the colour tests change: the background is navy now; the state is still on `body[data-state]`).
- The sign loads no network resource but its own page: the scenery is inline SVG, the fonts are the page's own.
- The scoreboard fetches nothing while the setting is off; a fetch failure never breaks the status route.
- `fits()` at 1280 by 800 and at 800 by 1280 (`fits` as the room page tests define it, applied to the sign: no page scroll, no scroll inside `main`).

## Review Focus

1. A room without a calendar must still show the brand row, the room name, "Free", the clock and date, with the Today box and This week hidden (Task 1 test `test_the_sign_without_a_calendar_keeps_its_brand_name_and_clock`).
2. The week view must group by the device's local day across a month boundary and return to Today on its own (Task 3 tests `test_the_week_route_groups_by_local_day_across_a_month_boundary`, `test_the_week_view_returns_to_today_after_thirty_idle_seconds`).
3. With the scoreboard on and the feed down, the sign must show no strip and no error, and the status route must still answer (Task 4 test `test_a_failed_fetch_keeps_the_last_answer_and_the_status_still_answers`).
4. The background choice must apply to every sign of the room after a reload and never require the sign to be touched (Task 2 test `test_the_background_choice_made_on_the_table_shows_on_the_sign`).
5. A long room name and a long booking title must wrap inside the sign at both sizes without pushing the clock off or overlapping the scenery (Task 1 test `test_long_names_wrap_inside_the_sign_at_both_sizes`).

def sign_colors(page):
    rail = page.locator(".rail").evaluate("e => getComputedStyle(e).backgroundColor")
    chip = page.locator(".chip").evaluate("e => getComputedStyle(e).backgroundColor")
    body = page.evaluate("getComputedStyle(document.body).backgroundColor")
    return rail, chip, body


def test_the_sign_shows_the_status_as_a_rail_a_chip_and_a_tint_on_navy(browser):
    skip_if_day_ends_within(1)
    with PageServer(calendar_events=[event("e1", "Design review", 8)]) as server:
        page = browser.new_page(viewport={"width": 1280, "height": 800})
        page.goto(f"http://127.0.0.1:{server.port}/sign", wait_until="networkidle")
        page.wait_for_function("document.body.dataset.state === 'soon'", timeout=5000)
        rail, chip, body = sign_colors(page)
        assert rail == chip == "rgb(232, 160, 19)" and body == "rgb(0, 22, 54)"      # amber on navy, never an amber wall
        assert page.locator("#chip-text").inner_text() == "Design review starts in 8 minutes"
        assert page.locator("#scene svg").count() == 1
        assert page.locator("#scene .fill").first.evaluate("e => getComputedStyle(e).fill") == "rgb(232, 160, 19)"
        assert page.locator("#company").inner_text() == "Crystal Practice Management"
        assert fits(page)
        page.close()


def test_the_sign_without_a_calendar_keeps_its_brand_name_and_clock(browser):

def test_long_names_wrap_inside_the_sign_at_both_sizes(browser):
